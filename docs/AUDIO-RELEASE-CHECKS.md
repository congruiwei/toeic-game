## 功能位置与使用范围

| 入口 | 行为 |
| --- | --- |
| 设置 → 音频 | 默认优先录音；可切换系统语音、调节 0.75×–1.2× 速度，按听力／单词／阅读／日语分组下载、取消或删除音频 |
| 普通练习答题后 | 英文句子点读、听力逐句重听与循环；“看懂每一个选项”显示词性、中日释义及逐项理由 |
| 词卡、方法卡、表达本 | 在允许查看的学习内容旁点读；表达复习翻面前仅开放当前提示一侧 |
| 练习地图 → 模拟考试 | 录音模式先准备本套听力，完成后由用户点击开始；交卷后回顾开放点读和逐句重听 |
| 练习地图／学习报告 → 我的单词本 | 从选项收藏准确义项，按英中／英日方向翻卡复习，随 JSON 进度导入导出 |

英语录音使用 Heart、Puck、Bella，均为美式；日语为 Alpha。系统口音和声音设置只影响设备语音。首页不下载整库音频；可选解析、搭配、干扰词或方法卡英文缺少文件时使用系统后备。首次点击若需异步取清单，会先解锁文件播放器；没有可用录音且系统需要新的用户手势时，明确提示再点一次。设备是否能离线合成系统声音仍取决于其已安装语音。

答题前保留题型必要的听力入口，不开放答案、翻译、选项释义或新增点读。Part 6 同篇全部完成后才可点读填好答案的整篇；收藏来源只填当前已答空，其他空仍保留标记。模考在交卷前不开放自由点读。个人词本自评只更新 FSRS，不增加客观答题量、正确率、估分或 XP。详见 [播放与点读说明](AUDIO-PLAYBACK.md)及[选项与个人词本说明](OPTION-DETAILS.md)。

## 大词本、组合输入及缓存竞态

下列是此前针对明确性能问题的独立测量，**当时后台合成与识别仍在运行**，与上文无并行负载的最终加载对照分开统计。

- **1,000 词个人本：** WebKit 390px 深色、未加 CPU 降速，初次打开到两次动画帧从 1462 ms 降至 105 ms，后两次从 1066／1102 ms 降至 62／44 ms；主区域 DOM 元素从 12,013 降至 615，清空搜索从 988 ms 降至 62 ms。每次展示 50 条，搜索与 FSRS 仍覆盖全本。组合输入「請求」保持原输入节点与焦点，确认组词后再筛选，重复尾随 input 不触发再次重绘。
- **5,000 个缓存响应：** 独立 WebKit 390px 深色缓存真实 M4A，共 101,880,000 字节。逐个精确读取正文的热扫描从 7325 ms 降至 3896 ms；最多 4 路并发，结果仍为准确字节数与文件数。清单请求从等待扫描后的 8611 ms 改为 42 ms 发起，按钮不再等待容量统计。
- **删除与旧统计竞争：** 原实现删除后先显示 0，随后旧 Cache 句柄扫描又显示 5,000 个文件，实际缓存已为空。修复后旧 UI 请求取消，统计 API 在删除代号变化后重开当前缓存；不新增持久索引，不用 Content-Length 代替真实正文。7 项缓存单测及真实 WebKit 4 项检查已通过；独立第 3 阶段副本的 1,000 条缓存检查也通过。
- **元数据与选项缓存写入：** 已验证的内容才可持久化，SW 不另写未经页面验证的响应。音频坏 HTML／错误指纹的真实 SW 回归见上表。选项包按代号与写入队列处理逆序返回、已经开始的旧写入及失败后重试；第 5 步两引擎三宽已通过真实 SW 的旧响应延迟、HTML 后备和离线冷重开检查。最终全套结果见上表。

这些测量使用桌面 WebKit 和隔离存储，未操作真实学习存档；重复媒体可能受文件系统缓存影响，没有测量真机内存上限。
