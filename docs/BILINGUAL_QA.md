## 日文优先复核清单：10 项

同样按 3 项词汇、3 项听力、4 项语法／阅读分组；日语语气应服务于原场景，不能因改成敬体而增加承诺、许可或命令。

| 分类 | 精确键 | 复核重点与当前处理 |
| --- | --- | --- |
| 词汇 | `v-franchisee/example/0`、`v-franchisee/example/1` | 同一词卡的两句分别说明 franchise 和 franchisee；“フランチャイズ”与“加盟経営者”不能混为一项，保留许可持有人及支付品牌使用费的关系。本行按一张词卡计一项。 |
| 词汇 | `v-artifact/example/0` | accessioned 采用“収蔵登録”，Roman 采用“ローマ時代”；保留先记录出土过程、再入藏的顺序，不泛化为收到一件物品。 |
| 词汇 | `v-term-condition/example/0` | term 此处是“条項”，不是期间或术语；Duration 栏名保留，条款将租期定为 3 年。 |
| Part 2 | `p2-069/options/2/0` | “エレベーターは5階まで”只说明电梯停靠范围；不能写成“最上階は5階”，后者擅自限定整栋建筑楼层。 |
| Part 3 | `p3-g04/turns/1/2` | picks up every note 是房间能听见音乐的语境；采用“音がすべて聞こえてきます”，不能译成笔记或录音器材拾音。 |
| Part 4 | `p4-g26/turns/0/1` | “使用後にリサイクルできる”与原料已经符合再生材料认证要求不同；保留“この条件を満たしません”的否定。 |
| Part 5 | `gram-conditional-09/sentence/0` | were to waive／would 表示假设免收费用后的预算结果；用“免除してくれれば…収まるでしょう”，不能暗示供应商已同意免收。 |
